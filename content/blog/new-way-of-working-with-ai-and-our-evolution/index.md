For most of my career, working with computers meant giving them precise instructions. I wrote the code, searched for answers, and operated every tool. Computers were fast but passive.

AI changes that relationship. We now describe outcomes, provide context, set constraints, and review work produced for us. This is not only a faster way to work. It is a different way to work.

## From operator to collaborator

AI first behaved like autocomplete. Then it became a pair programmer. Now agents can inspect a codebase, run commands, write tests, and implement changes. Several agents can work on separate parts of one problem.

Our effort moves from producing every artifact toward defining problems, directing work, and verifying results.

## The new unit of work

A prompt is not the work. The work is a feedback loop:

1. Understand the problem.
2. Supply relevant context.
3. Delegate a bounded task.
4. Inspect the result.
5. Verify it with tests or human review.
6. Improve the context for next time.

This makes tests, documentation, and clear standards more valuable. They guide both people and agents.

## Judgment becomes more important

When AI can produce code, writing, and analysis quickly, producing a first draft is no longer the whole job. Value moves toward choosing worthwhile problems, understanding tradeoffs, spotting plausible mistakes, and accepting responsibility for results.

AI increases the leverage of both good and bad judgment.

## Avoiding cognitive atrophy

Delegating every difficult task may make us faster but less capable. Struggle remains part of learning.

My current balance is:

- delegate repetition, not responsibility;
- form an opinion before asking AI;
- inspect important work deeply enough to explain it;
- keep practising foundational skills;
- use saved time to learn.

We should automate toil without automating thought.

## Evolving with our tools

So how do we evolve with this rapid progress? Well, you need to understand that the de facto way of working like before is just gone and dusted. We need to get better at managing our tasks, setting off async tasks, consolidating the outputs, and discarding the ones that are not as successful. The cost of experimenting has reduced by 100x, so you should try each approach and pick up a winner. Also, one should go hard and deep into fundamentals. In order to be able to judge something, you need to know what's underneath it. As stacking features is super easy now, stacking code debt is even easier. So all the guardrails should be present. Earlier, you were programming the inner layer yourself; now, you are programming the agentic layer to get what you want. Ultimately, the end result is going to be the same. But you can massively increase the quality of what is being delivered here. The bottom line is that very few people will adapt to this and survive when the next wave of highly capable AI agents comes and is able to write better code than 90% of the folks. So the only way to still have a profession here is to adapt and get better at "Programming Agents".
